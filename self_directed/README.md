# Self-directed track

Read the main `README.md` first for the scenario, the facts, and the data dictionary.

## Your task

Work out whether the two buttons get different results, and decide which one to roll out.

1. **Plan.** Before opening any data, write down how you will run and judge this test. Use `plan_template.md`.
2. **Analyze days 1 to 5.** Open `data/experiment_days_1-5.csv`. The product manager wants an answer today. What do you tell them?
3. **Analyze all 14 days.** Add the days 6 to 14 file your facilitator gives you. Does your recommendation change?

Work out whether the two buttons get different results, and decide which one to roll out.
Feel free to explore what is interesting to you - create a dashboard with real-time results, implement CUPED, mSPRT, grouped sequential tests,  bayesian methods, etc.
